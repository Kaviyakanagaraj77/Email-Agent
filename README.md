# 📧 Email Agent

A Java-based email assistant designed to help users generate professional and context-aware email replies quickly and efficiently.

## 🚀 Features

* Generate professional email replies
* Create context-based responses
* Save generated replies
* Simple and easy-to-use application
* Helps reduce time spent writing emails
* Easy to customize and extend

## 🛠️ Technologies Used

* Java
* JavaScript
* Node.js
* HTML
* CSS
* Git & GitHub

## ⚙️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/Kaviyakanagaraj77/Email-Agent.git
```

### 2. Open the project

```bash
cd Email-Agent
```

### 3. Compile and run

```bash
javac Main.java AIReply.java
java Main
```

Make sure Java is installed on your system.

## 🔐 API Key Security

For security, the API key should **never be written directly inside the source code**.

Use an environment variable:

```text
OPENAI_API_KEY=your_api_key
```

The Java application can access it using:

```java
System.getenv("OPENAI_API_KEY");
```
